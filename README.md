## 📱 About the App

**Card Matching** is a free, offline memory card matching puzzle game available on the Google Play Store.

### Key Features
- 🎴 Classic memory card matching gameplay
- 🎯 3 difficulty levels (Easy 4×4, Medium 6×6, Hard 8×8)
- 🎨 4 card themes (Emojis, Animals, Fruits, Shapes)
- 🌓 Light & Dark mode
- 📅 Daily challenges
- 👥 Local 2-player mode
- 🏆 12 achievements to unlock
- 🔊 Sound effects & vibration feedback
- 💯 Completely offline — no internet required
- 🚫 No ads, no data collection, no tracking

## 🔒 Privacy Commitment

We do **not** collect, store, transmit, or share any user data. The app works entirely offline and all game data (scores, preferences, achievements) stays on the user's device.

- ❌ No analytics
- ❌ No advertising
- ❌ No third-party services
- ❌ No internet permissions
- ✅ 100% private
